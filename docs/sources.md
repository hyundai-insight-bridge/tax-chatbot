---

## 문서 추가 방법

1. PDF를 `data/` 폴더에 넣습니다.
2. 이 문서의 **문서 목록** 표에 새 ID와 정보를 추가합니다.
3. **문서별 상세**에 텍스트 레이어 유무와 출처 표기 방식을 적습니다.
4. 인덱스를 다시 생성한 뒤, 새 기기에 대한 평가 질문을 `eval/`에 추가합니다.
